# 🏫 현재가 미래로 - 중랑구 아동 안심 스쿨존 웹 서비스

> **중랑구 초등학생과 학부모를 위한 데이터 기반 스쿨존 위험지수 시각화 및 실시간 위험 제보 플랫폼**

---

## 📌 1. 프로젝트 개요
* **주요 목표**: 중랑구 내 어린이보호구역 및 CCTV 데이터를 바탕으로 스쿨존 위험지수를 시각화하고, 사용자가 직접 위험 지역을 제보할 수 있는 웹 서비스입니다.
* **주요 기능**:
  * 🗺️ **스쿨존 안심 지도 (메인 페이지)**: 백엔드 연동 상태 확인 및 제보 게시판 이동 버튼 제공
  * 🚨 **위험 지역 제보하기 (제보 페이지)**: 실시간 위험 요인 제보 및 메인 화면 복귀 기능
  * 🔌 **백엔드 Health Check API**: 서버 통신 상태 실시간 점검 (`/api/health`)

---

## 🛠️ 2. 시작하기 전 필수 준비사항 (Prerequisites)
프로젝트를 실행하려면 컴퓨터에 아래 프로그램이 설치되어 있어야 합니다.
1. **[Node.js](https://nodejs.org/)** (v18 이상 권장 - 설치 시 npm이 함께 설치됩니다.)
2. **[Git](https://git-scm.com/)**
3. **VS Code** (코드 편집기)

---

## 🚀 3. 처음부터 실행하기 (단계별 가이드)

프로젝트를 내 컴퓨터로 가져와서 백엔드와 프론트엔드를 구동하는 전체 순서입니다.

### [1단계] 깃허브에서 프로젝트 내려받기 (Git Clone)
1. 코드를 저장할 폴더(예: 바탕화면)에서 터미널(또는 Git Bash)을 엽니다.
2. 아래 명령어를 입력하여 깃허브 저장소를 클론합니다.
   git clone [https://github.com/rkqdhtqkznl-ship-it/seoil-capstone.git](https://github.com/rkqdhtqkznl-ship-it/seoil-capstone.git)
3. 생성된 프로젝트 폴더로 이동합니다.
4. VS Code로 해당 폴더를 엽니다.

### [2단계] 백엔드(Server) 실행하기
1. VS Code 상단 메뉴에서 [터미널] ➔ [새 터미널]을 클릭하여 터미널을 엽니다.
2. server 폴더로 이동하여 필요한 라이브러리를 설치합니다.(아래 명령어 사용)
    cd server
    npm install
3. 백엔드 개발 서버를 실행합니다.(아래 명령어 사용)
    npm run dev
4. 성공 확인: 터미널에 서버가 5000번 포트에서 실행 중입니다. 메시지가 뜨고, 브라우저에서    http://localhost:5000/api/health에 접속했을 때 아래 화면이 나오면 성공입니다!
    { "message": "백엔드 서버가 정상적으로 실행 중입니다!" }

### [3단계] 프론트엔드(Client) 실행하기
1. VS Code 우측 상단 터미널 패널에서 + (새 터미널) 버튼을 누릅니다.
2. client 폴더로 이동하여 필요한 라이브러리를 설치합니다.(아래 명령어 사용)
    cd client
    npm install
3. 프론트엔드 개발 서버를 시작합니다.(아래 명령어 사용)
4. 성공 확인: 잠시 후 브라우저가 자동으로 열리며 http://localhost:3000에 접속됩니다.
    파란색 박스에 🔌 백엔드 연결 상태: 백엔드 서버가 정상적으로 실행 중입니다! 문구가 뜨면 연동 완료입니다.
    제보게시판이동 ➔ 버튼을 눌러 제보 페이지로 화면이 정상 전환되는지 확인해 보세요!
❓ 자주 묻는 질문 (Troubleshooting)
    Q1. npm 명령어를 찾을 수 없대요.

    Node.js가 설치되지 않았거나 환경변수가 등록되지 않은 것입니다. Node.js 공식 홈페이지에서 설치 후 VS Code를 재시작해 주세요.

    Q2. 프론트엔드 화면에 백엔드 연결 에러(❌ 백엔드 서버와 연결하지 못했습니다.)가 떠요.

    백엔드 터미널(npm run dev)이 꺼져 있거나 5000번 포트에서 실행 중이 아닌지 확인해 주세요. 백엔드와 프론트엔드 터미널이 동시에 켜져 있어야 합니다.

    Q3. 실행 중인 서버를 끄고 싶어요.

    해당 터미널 창을 클릭한 뒤 키보드에서 Ctrl + C를 누르고, y를 입력한 뒤 엔터를 치면 꺼집니다.
