# 현재가 미래로 - 중랑구 통학로 안전지도

React 기반 팀 프로젝트 데모입니다. 카카오 지도 API 키가 없어도 실행할 수 있도록 OpenStreetMap 타일과 Leaflet을 사용합니다.

## 실행 방법

1. Node.js LTS를 설치합니다.
2. 터미널에서 `client` 폴더로 이동합니다. (cd client)
3. 아래 명령어를 실행합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 포함 기능

- 중랑구 중심의 지도 및 예시 위치 마커
- 스쿨존 / 불법 주정차 / CCTV / 사용자 제보 표시 필터
- 지도 정보 검색 및 마커 상세 보기
- 위험정보 목록
- 위험정보 제보 폼
- 제보 데이터를 브라우저 `localStorage`에 저장
- 모바일 화면 대응

## 데이터와 운영 관련 참고

지도 마커는 기능 확인을 위한 **예시 데이터**이며, 공식 기관에서 제공하는 실제 위치 정보가 아닙니다. 제보는 현재 브라우저에만 저장되고 팀원 간 공유되지 않습니다. 실제 서비스로 운영하려면 공식 데이터 출처 검증, 좌표 데이터, 서버/API, 데이터베이스, 개인정보·보안 정책이 필요합니다.

지도 타일은 인터넷 연결이 필요하며 OpenStreetMap 기여자에게 출처를 표시합니다.
